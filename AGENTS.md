# Agent Guidelines

## Project
This is my personal portfolio website. It includes my resume, work experience, projects, clubs, and information about me.

## Design Consistency
Design consistency is very important for this website.

Before making a new page or changing an existing page:
- Look at the existing pages first.
- Match the existing visual style instead of creating a new design.
- Reuse the same colors, fonts, navigation, spacing, buttons, borders, and other design elements.
- Keep the same overall layout style across the website.
- New pages should feel like they belong to the same website.
- Do not introduce new colors, fonts, or design styles unless I specifically ask for them.

## Existing Design
The current website is the source of truth for the visual design.

When I ask for a change:
- Preserve the existing design unless I specifically ask to change it.
- Reuse existing CSS whenever possible.
- Do not redesign unrelated parts of the page.
- Do not change the navigation or overall page structure unless requested.
- Keep repeated elements consistent across every page.

## New Pages
When creating a new page:
- First inspect the existing pages and styles.
- Use the same navigation and visual system.
- Reuse existing CSS classes when possible.
- Match existing typography, colors, spacing, and layout.
- Make sure the page is responsive.
- Only create new styles when the existing styles cannot accomplish what is needed.

## Code
- Use semantic HTML when possible.
- Keep HTML and CSS organized and readable.
- Avoid unnecessary duplicate CSS.
- Keep the code simple enough for me to understand and edit myself.

## Working With AI
- Follow my request without changing unrelated parts of the website.
- Do not make major design decisions for me unless I ask.
- Preserve my existing content unless I ask for it to be changed.
- If my request conflicts with the existing design system, prioritize consistency unless I explicitly ask for a redesign
